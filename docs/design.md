# Patternity Design

## Parser

The `patternity` parser extracts StepMania song and chart (note) data into a model that enables pattern recognition and analytics.

### Requirements

- Read and parse `.sm` and `.ssc` file formats for StepMania
- Read and parse 4-panel (singles) charts. *Doubles are out of scope.*
- Capture chart metadata including song header information, groove radar statistics, and chart metadata
